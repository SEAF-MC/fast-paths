# fast-paths

A plugin with the sole purpose of making paths actually useful. This is intended for private use but I will do my best to provide support if needed.

Features:
 - Gives the speed effect to players standing on path blocks.
 - Allows players to step up one one block without jumping (if both are path blocks).

Commands (both require fastpaths.admin or OP):
 - `/fastpaths reload` reloads the plugin
 - `/fastpaths info` displays settings and lists effected players

Disclaimer: This plugin was created entirely with Gemini 3.8 but as with all my AI projects It has been throughly tested.
